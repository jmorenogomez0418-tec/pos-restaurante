# 🍽️ POS Restaurante

Sistema POS web para la gestión de pedidos, mesas y facturación en restaurante.

## 🚀 Funcionalidades

- Gestión de mesas
- Registro de pedidos
- Visualización de pedidos en tiempo real
- Cierre de cuenta
- Clasificación por puntos de venta

## 🛠️ Tecnologías

- PHP
- MySQL
- JavaScript
- HTML/CSS
- XAMPP

## 📂 Estructura

- config: conexión a la base de datos
- controllers: lógica del sistema
- views: interfaz de usuario
- database: script SQL
